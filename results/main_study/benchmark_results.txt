H2 VQE benchmark results, ERAU Vega HPC cluster
===============================================

Hardware: AMD EPYC 9654 (192 cores per node), 4x NVIDIA H100 PCIe.
Workload: H2, STO-3G, 4 qubits, 100 bond lengths from 0.35 to 3.0 Angstrom,
at most 300 VQE iterations per bond length.


SINGLE-PROCESS RUNS

Script                 Device           Optimizer             Stop rule              Start per bond   Iterations   Runtime    Time/iter
main.py                lightning.qubit  PennyLane Adam 0.01   fixed 300              zeros            30,000       593.95 s   0.0198 s
vqe_serial_optax.py    lightning.qubit  Optax Adam 0.05,      |dE| < 1e-8 or 300     previous bond     7,033       143.80 s   0.0204 s
                                        Catalyst qjit
vqe_gpu.py             lightning.gpu    Optax Adam 0.05       |dE| < 1e-8 or 300     zeros            11,345       164.91 s   0.0145 s
vqe_qjit.py            lightning.qubit  Optax Adam 0.05,      |dE| < 1e-8 or 300     previous bond         -       171.79 s   -
                                        Catalyst qjit

Time/iter is the runtime divided by the iteration count. It includes the
Hartree-Fock Hamiltonian construction for each bond length.

The runtime of vqe_serial_optax.py is 4.13x lower than main.py and its
iteration count is 4.3x lower. The runs differ in four settings (compilation,
learning rate, stop rule, start), and no run changes one setting at a time.


MPI RUNS (vqe_mpi.py, Optax Adam 0.05 + Catalyst qjit)

Ranks   Runtime (rank 0)
    2   8.45 s
    4   6.07 s
    8   5.48 s
   16   5.06 s
   32   5.04 s

vqe_mpi.py records the elapsed time on rank 0 only, before the gather.

These runtimes are not compared with the single-process runs. The serial job
requested one core (ppn=1). The MPI jobs ran under other allocations. Split
the per-bond times in logs/serial_optax_output.log the same way as
vqe_mpi.py: rank 0 gets 73.5 s of work at 2 ranks, against 8.45 s measured.
So the jobs had different resources, and the runtime ratio is not a parallel
speedup.
